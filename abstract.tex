% Main Content
\begin{spacing}{1.45}
\noindent
Side-channel attacks (SCAs) pose a major threat to cryptographic hardware, as attackers can extract secret information by analyzing physical leakages such as power consumption. Techniques like Correlation Power Analysis (CPA) and Differential Power Analysis (DPA), along with modern machine learning-based attacks, have proven effective against secure algorithms. This highlights the need for strong hardware-level countermeasures to reduce leakage and improve security.

\vspace{0.45cm}

\noindent
This work proposes Binary Decision Diagram (BDD)-based dual-rail logic circuits to mitigate power analysis attacks. The key feature of this approach is balanced switching activity, where each circuit path undergoes an equal number of transitions. By ensuring uniform switching behavior through structured transistor connections, the design minimizes data-dependent variations and reduces the chances of leakage during cryptographic operations.

\vspace{0.45cm}

\noindent
The system implements the Advanced Encryption Standard (AES) on an FPGA platform with secure inter-board communication using the Serial Peripheral Interface (SPI) protocol. Verilog HDL is used for design and implementation, while simulation and hardware testing validate functionality. The system ensures correct encryption and reliable data transfer between FPGA boards without affecting output integrity.

\vspace{0.45cm}

\noindent
The integration of BDD-based logic, dual-rail encoding with precharge-evaluate operation, and SPI communication provides an efficient and scalable solution for secure hardware design. This approach reduces side-channel leakage while maintaining performance, making it suitable for practical deployment in modern embedded and cryptographic systems.
